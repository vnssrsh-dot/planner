# Шрифти

Сюди покладіть файл шрифту заголовків **Kyiv*Type Sans** (автор — Дмитро Растворцев):

- `KyivTypeSans-VarGX.ttf` — варіативний файл з архіву шрифту, або
- `KyivTypeSans-VarGX.woff2` — те саме у форматі woff2 (менший розмір).

Назва файлу має збігатися з однією з наведених. Більше нічого міняти не потрібно:
`style.css` вже підключає шрифт. Поки файлу немає, заголовки показуються шрифтом Manrope.

Перед публікацією перевірте ліцензію з архіву шрифту: різні сайти вказують різні умови.
